문제

예시 공통수학1 · 이차방정식과 이차함수
이차함수 y = x^2 - 4x + k의 그래프가 x축과 서로 다른 두 점에서 만나도록 하는 실수 k의 값의 범위를 구하시오.
접근 · 그래프와 x축의 교점 개수는 이차방정식 x^2 - 4x + k = 0의 실근 개수와 같아요. 판별식으로 조건을 식으로 바꿔 봅시다.

단계별 풀이

0 / 4 단계
1

교점을 방정식으로 바꾸기

이차함수 y = x^2 - 4x + k가 x축과 만나는 점의 x좌표는 y = 0을 대입한 이차방정식의 실근입니다.

$\rightarrow x^2 - 4x + k = 0$

2

앞 단계를 먼저 해결해 보세요

서로 다른 두 점에서 만나려면 이차방정식이 서로 다른 두 실근을 가져야 합니다.

따라서 판별식 D > 0 (또는 짝수 판별식 D/4 > 0) 이어야 합니다.

3

앞 단계를 먼저 해결해 보세요

짝수 판별식 공식 D/4 = b'^2 - ac를 사용합니다.

$\frac{D}{4} = (-2)^2 - 1 \cdot k = 4 - k > 0$

4

앞 단계를 먼저 해결해 보세요

부등식 4 - k > 0을 풀어주면 최종 정답을 얻습니다.

정답: $k < 4$

내 답 확인

정답: k < 4
해설: D/4 = (-2)^2 - k = 4 - k > 0 \implies k < 4입니다.

개념과 공식

판별식

$D = b^2 - 4ac$

D > 0이면 서로 다른 두 실근,
D = 0이면 중근, D < 0이면 서로 다른 두 허근을 가져요.

그래프와 x축의 위치 관계

y = ax^2 + bx + c의 그래프와 x축의 교점 개수는 ax^2 + bx + c = 0의 실근 개수와 같아요.

  • D > 0: 두 점에서 만남
  • D = 0: 접함
  • D < 0: 만나지 않음

짝수 판별식

$\frac{D}{4} = b'^2 - ac \quad (b = 2b')$

x의 계수가 짝수일 때 계산을 줄여 줘요.
